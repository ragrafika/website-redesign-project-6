# Архив калькулятора информационных стендов

Дата архивации: 2026-09-24

## Описание
Калькулятор расчёта стоимости информационных стендов (инфостендов) с карманами для буклетов.

## Основные возможности
- Расчёт по ширине и высоте стенда (см)
- Выбор толщины ПВХ (3/5/8/10 мм)
- Выбор типа печати (интерьерная, ламинированная, УФ, аппликация Оракал)
- Настройка заголовка: текст, шрифт, цвет фона
- Карманы форматов A5/A4/A3/A2 с указанием количества
- Загрузка собственного изображения с выбором положения (растянуть/по вертикали/по горизонтали)
- Визуальный превью стенда в реальном времени
- Расчёт цены в трёх пакетах: эконом/стандарт/премиум

## Структура файлов
- `StandCalculator.tsx` — главный компонент-обёртка
- `StandPreview.tsx` — старая версия превью (не использовалась в CalculatorSection на момент архивации)
- `stand/StandParametersForm.tsx` — форма ввода параметров
- `stand/StandPreviewCard.tsx` — актуальная карточка визуального превью
- `stand/StandPriceSection.tsx` — блок расчёта и вывода цены, кнопка заказа через OrderDialog

## Интеграция (до архивации)
Был подключен в `src/components/sections/CalculatorSection.tsx` как один из калькуляторов (переключатель "Инфостенды" / "Вывеска для павильона").
Доступен был по адресу `/calculator#stand`, а также через карточку в `CalculatorsBlockSection.tsx` на главной странице.

## Причина архивации
Калькулятор стендов убран с сайта по запросу клиента. Все ссылки на него удалены со страниц (Header, Footer, HeroSection, CalculatorsBlockSection). Файлы сохранены для возможного восстановления в будущем.
